3. 수정내용
   비유: 눈 감고 산 내려오기
   당신은 산 위에 있어요.
   눈을 감고 있어요. (전체 지도가 없음)

전략:

1. 발로 경사를 느낌 (기울기 계산)
2. 경사가 내려가는 방향으로 한 걸음
3. 다시 경사 느끼기
4. 반복!

→ 점점 산 아래(최저점)로 이동!
AI에서 경사하강법
목표: 손실(Loss) 최소화 = "얼마나 틀렸나?" 줄이기

1단계: AI가 예측
Q(상황, 오른쪽) = 7.0 ← AI가 예측한 값

2단계: 실제 결과 확인
실제 보상: +100 (목적지 도달!)
올바른 Q값: 10.0

3단계: 오차 계산
오차(Loss) = (7.0 - 10.0)² = 9.0

4단계: 기울기 계산 (어느 방향으로 수정?)
기울기 = 2 × (7.0 - 10.0) = -6.0 ← 올려야 함!

5단계: 가중치 수정
새로운 Q값 = 7.0 + (학습률 × 6.0) = 7.6

6단계: 반복!
→ 점점 10.0에 가까워짐!
