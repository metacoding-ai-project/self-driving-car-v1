### 🔧 v0 코드 소개

**car.py (if 기반 움직임)**

```python
def decide_action(self, environment):
    """if 규칙으로 다음 방향 결정"""
    goal_x, goal_y = environment.goal_pos

    # 1. 목적지까지의 거리 계산
    dx = goal_x - self.x   # 양수 = 오른쪽, 음수 = 왼쪽
    dy = goal_y - self.y   # 양수 = 아래쪽, 음수 = 위쪽

    # 2. 우선순위 방향 결정
    preferred = []
    if dx > 0:  preferred.append(RIGHT)   # 목적지가 오른쪽
    elif dx < 0: preferred.append(LEFT)   # 목적지가 왼쪽
    if dy > 0:  preferred.append(DOWN)    # 목적지가 아래
    elif dy < 0: preferred.append(UP)     # 목적지가 위

    # 3. 막혔으면 다른 방향 시도
    for direction in preferred:
        next_x, next_y = 목적지 방향으로 한 칸
        if not environment.is_wall(next_x, next_y):
            return direction  # 이 방향으로 이동!
```

### 🤔 왜 if 문으로는 안 될까?

**문제 1: 국소 최적화 함정 (Local Optima)**

```
목적지는 오른쪽에 있어요.
그런데 오른쪽은 벽으로 막혀 있어요.

if 규칙: "오른쪽은 막혔으니 아래로 가자!"
아래도 막혔으면?
if 규칙: "위로 가자!"
위도 막혔으면?
→ 같은 자리에서 뺑뺑이!
```

**문제 2: 경험이 없음**

```
❌ if 문: 항상 같은 규칙
   "막히면 이쪽, 막히면 저쪽"
   → 배우지 않음!

✅ AI (강화학습): 경험으로 학습
   "이 상황에서 오른쪽으로 갔더니 성공했어!"
   → 다음에는 더 잘함!
```

### 🧠 AI 개념: DQN이 뭔가요?

#### Q-값이란?

Q-값은 "이 상황에서 이 행동을 하면 얼마나 좋을까?"를 나타내는 숫자입니다.

```
현재 상황: 목적지가 오른쪽에 있고, 앞에 벽은 없음

Q(상황, 오른쪽으로 이동) = 8.5   ← 가장 높음!
Q(상황, 위로 이동)        = 3.2
Q(상황, 아래로 이동)      = 2.1
Q(상황, 왼쪽으로 이동)    = -5.0  ← 가장 낮음 (멀어짐)

AI는 Q값이 가장 높은 행동 선택!
→ 오른쪽으로 이동! ✅
```

#### 신경망(Neural Network)은?

```
입력층 (11개)          은닉층 (64개)         출력층 (3개)
┌─────────┐           ┌─────────┐           ┌─────────┐
│ 벽 정보 │──────────▶│         │──────────▶│ 직진 Q  │
│ (8개)   │           │  뉴런   │           │ 우회전 Q│
│ 방향    │           │         │           │ 좌회전 Q│
│ 목적지  │           │  (계산) │           └─────────┘
│ 방향    │           └─────────┘
└─────────┘

AI는 이 신경망으로 Q값을 계산합니다.
```

#### 어떻게 배우나요?

```
1. 행동 시도:    자동차가 오른쪽으로 이동
2. 결과 확인:    목적지에 가까워졌다! (+0.5 보상)
3. 신경망 수정:  "오른쪽 이동의 Q값을 높여!"
4. 반복:         500번 반복하면 점점 잘하게 됨!
```

### 🧠 AI 개념: 과적합(Overfitting)이란?

```
학생이 수학 문제집의 1번 문제만 1000번 풀었어요.
1번 문제는 완벽하게 풀 수 있어요!

하지만 시험에는 2번 문제가 나왔어요.
→ 못 풀어요! ❌

이게 과적합입니다!
```

```
AI도 마찬가지:

v1 학습:
- 항상 같은 맵에서 학습
- 항상 같은 방향(위쪽)으로 시작
→ 이 맵, 이 방향에서만 잘함 (과적합!)

새로운 맵 테스트:
→ 완전히 실패!
```

### 📝 v1 정리

**v1의 문제점:**
- ❌ 항상 같은 방향에서 시작 → 한쪽으로만 이동
- ❌ 항상 같은 맵에서 학습 → 새로운 맵에서 실패
- ❌ 너무 빨리 탐험 중단 → 다양한 방법 못 배움

**해결 방법:**
- ✅ 여러 방향에서 시작해보자

### 🧠 AI 개념: 경사하강법(Gradient Descent)

> **"AI가 실수에서 배우는 방법"**

메타코딩이 AI를 수정할 때, 그 안에서는 어떤 일이 벌어질까요?

#### 비유: 눈 감고 산 내려오기

```
당신은 산 위에 있어요.
눈을 감고 있어요. (전체 지도가 없음)

전략:
1. 발로 경사를 느낌 (기울기 계산)
2. 경사가 내려가는 방향으로 한 걸음
3. 다시 경사 느끼기
4. 반복!

→ 점점 산 아래(최저점)로 이동!
```

#### AI에서 경사하강법

```
목표: 손실(Loss) 최소화 = "얼마나 틀렸나?" 줄이기

1단계: AI가 예측
   Q(상황, 오른쪽) = 7.0  ← AI가 예측한 값

2단계: 실제 결과 확인
   실제 보상: +100 (목적지 도달!)
   올바른 Q값: 10.0

3단계: 오차 계산
   오차(Loss) = (7.0 - 10.0)² = 9.0

4단계: 기울기 계산 (어느 방향으로 수정?)
   기울기 = 2 × (7.0 - 10.0) = -6.0  ← 올려야 함!

5단계: 가중치 수정
   새로운 Q값 = 7.0 + (학습률 × 6.0) = 7.6

6단계: 반복!
   → 점점 10.0에 가까워짐!
```

#### 시각화

```
손실(Loss)
   │
10 │
   │   ▼ 처음
 8 │    \
   │     \
 6 │      \
   │       \
 4 │        \
   │         \
 2 │          \___________
   │                      ← 최저점! (완전히 학습됨)
 0 └──────────────────────────────▶ 학습 횟수
   0    500   1000  1500  2000  3000
```

### 🧠 AI 개념: Learning Rate란?

> **"AI가 얼마나 빠르게 배울지 조절하는 손잡이"**

#### 비유

```
책 읽는 속도에 비유해볼게요:

빠르게 읽기 (큰 Learning Rate):
📖 → 한 번에 챕터 전체 훑기
→ 전체 내용 빠르게 파악!
→ 하지만 세부 내용 놓침

천천히 읽기 (작은 Learning Rate):
📖 → 한 문장씩 꼼꼼하게
→ 세부 내용까지 완벽 이해!
→ 하지만 시간이 오래 걸림
```

#### Learning Rate Scheduling

```
가장 효율적인 방법:

1단계 (처음): 빠르게 읽어서 전체 파악!
2단계 (중간): 꼼꼼하게 읽어서 이해!
3단계 (마지막): 중요한 부분 정독!

→ 빠르면서도 정확!
```

#### 경사하강법 + Learning Rate

```
Learning Rate가 너무 크면:
산 내려오기에서 너무 큰 보폭
→ 최저점을 지나쳐 반대편으로! ❌

  Loss
  │
  │   ╱
  │  ╱  → 너무 큰 폭!
  │ ╱
  └──────▶

Learning Rate가 너무 작으면:
아주 조금씩만 이동
→ 너무 오래 걸림! ❌

Learning Rate Scheduling:
처음엔 크게, 나중엔 작게
→ 빠르고 정확! ✅
```

class DQNAgent:

### 🔧 캐싱 코드 소개

```python
class ActionCache:
    """성공한 경험을 저장하는 캐시"""
    def __init__(self):
        self.cache = {}  # 상태 → 행동 매핑

    def get(self, state):
        """캐시에서 행동 가져오기"""
        state_key = tuple(round(x, 2) for x in state)
        if state_key in self.cache:
            return self.cache[state_key]['action']
        return None  # 캐시에 없으면 None
```

### 🤔 왜 73%에 머물렀을까?

### 🔍 분석: 부족한 부분들

#### 문제 1: 경험 재생이 단순함 (Priority 없음)

```
현재 v5의 경험 재생 방식:
┌──────────────────────────────────────┐
│ 경험 1: 벽에 충돌              │
│ 경험 2: 목적지 도달  ← 중요!  │
│ 경험 3: 이동 중                │
│ 경험 4: 이동 중                │
│ 경험 5: 이동 중                │
└──────────────────────────────────────┘
→ 모든 경험을 동등하게 학습
→ 중요한 경험(목적지 도달)도 같은 취급!

문제: "목적지 도달" 같은 희귀하고 중요한 경험을
      자주 학습해야 하는데 그렇지 않음!
```

**해결책: Prioritized Experience Replay**

```
중요도가 높은 경험을 더 자주 학습!

┌──────────────────────────────────────┐
│ 경험 2: 목적지 도달  (우선순위 높음) │──▶ 자주 학습!
│ 경험 1: 벽에 충돌   (우선순위 중간) │──▶ 가끔 학습
│ 경험 3: 이동 중     (우선순위 낮음)  │──▶ 드물게 학습
└──────────────────────────────────────┘

기대 효과: +5~8% 성공률 향상
```

#### 문제 2: 하나의 Q-Network가 두 역할 (과대 평가 문제)

```
현재 v5 DQN:
┌─────────────────────────────────────┐
│ Policy Network (하나의 신경망)       │
│ 역할 1: 어떤 행동이 좋은지 판단      │
│ 역할 2: 그 행동의 가치를 평가        │
└─────────────────────────────────────┘

문제: 같은 신경망이 판단+평가 동시에
→ 자기가 좋다고 판단한 행동을 과대 평가!
→ 실제보다 좋은 행동인 척 → 학습 불안정
```

**해결책: Double DQN**

```
┌──────────────────────┐   ┌──────────────────────┐
│ Policy Network       │   │ Target Network        │
│ 역할: "어떤 행동?"   │──▶│ 역할: "그 행동 가치?" │
│ (선택만)             │   │ (평가만)              │
└──────────────────────┘   └──────────────────────┘

→ 판단과 평가를 분리!
→ 과대 평가 문제 해결!
기대 효과: +3~5% 성공률 향상
```

#### 문제 3: 신경망 구조가 단순함

```
현재 v5 신경망:
입력(11) → 은닉(64) → 출력(3)

문제: 64개 뉴런으로 복잡한 판단?
     미로가 복잡할수록 더 많은 뉴런 필요!
```

**해결책: Dueling Network**

```
기존 DQN:
입력(11) → [은닉층] → Q값(3개)

Dueling DQN:
입력(11) → [은닉층] ─┬─▶ [상태 가치 V] ─┐
                    │                  ├──▶ Q값(3개)
                    └─▶ [행동 이점 A] ──┘

분리 이유:
V(상태): "이 상황 자체가 좋은가?" (위치)
A(행동): "이 행동이 얼마나 더 나은가?" (선택)

→ 더 풍부한 학습!
기대 효과: +4~7% 성공률 향상
```

#### 문제 4: 학습 맵이 너무 적음 (20개)

```
현재: 20개 맵에서만 학습
→ 비슷한 구조의 새 맵에서는 잘 대응
→ 완전히 다른 구조의 맵에서는 어려움

해결책:
┌─────────────────────────────────┐
│ 맵 다양성 늘리기                │
├─────────────────────────────────┤
│ 현재: 20개 맵                   │
│ 목표: 100개+ 맵                 │
│                                 │
│ 추가할 맵 유형:                  │
│ - 미로형 맵 (복잡한 구조)        │
│ - U자형 맵 (돌아서 가야 함)     │
│ - 나선형 맵 (연속 회전)         │
│ - 열린 맵 (장애물 적음)         │
└─────────────────────────────────┘

기대 효과: +3~5% 성공률 향상
```

#### 문제 5: 입력 정보 부족 (11개)

```
현재 상태 입력:
┌─────────────────────────────────┐
│ 주변 8칸 벽 정보 (8개)          │

놓치는 정보:

- 가장 최근 이동 이력
```

**해결책: 입력 정보 확장**

```
개선된 상태 입력:
┌─────────────────────────────────┐

기대 효과: +3~5% 성공률 향상

### 📊 개선 로드맵

```
현재 v5: 73%
│
├─▶ Double DQN 적용:           +3~5%  → 76~78%
│
├─▶ Prioritized Replay 적용:   +5~8%  → 81~86%
│
├─▶ Dueling Network 적용:      +4~7%  → 85~93%
│
├─▶ 맵 다양성 증가 (100개+):   +3~5%  → 88~95%
│
└─▶ 입력 정보 확장:            +2~3%  → 90~98%

### 💡 그 외 알려진 개선 기법들

```
1. Prioritized Experience Replay (PER)
   중요한 경험을 더 자주 학습
   → 희귀한 성공 경험을 놓치지 않음

2. Double DQN
   판단(Policy)과 평가(Target)를 분리
   → 과대 평가 문제 해결

3. Dueling DQN
   "이 상황이 좋은가"와 "이 행동이 좋은가"를 분리
   → 더 풍부한 표현력

4. Multi-step Returns (n-step)
   1번 이동의 결과만 보지 않고 3~5번 이동 결과 봄
   → 더 멀리 내다보는 AI

5. Noisy Networks
   신경망에 노이즈 추가로 탐험 자동화
   → Epsilon 수동 조절 불필요
```

## 📚 용어 정리

| 용어 | 설명 | 비유 |
|------|------|------|
| 강화학습 | 보상으로 배우는 AI | 게임하면서 실력 향상 |
| DQN | AI의 뇌 (신경망) | 계산하는 두뇌 |
| Q값 | 행동의 예상 점수 | "이 행동 얼마나 좋지?" |
| Epsilon (ε) | 탐험 확률 | 새 식당 vs 단골 식당 |
| 경사하강법 | AI가 오차를 줄이는 방법 | 눈 감고 산 내려오기 |
| 과적합 | 특정 데이터만 잘함 | 한 문제만 외워서 시험 통과 |
| 일반화 | 새 상황에도 잘함 | 어떤 문제도 풀 수 있는 실력 |
| Learning Rate | 학습 속도 | 책 읽는 속도 |
| Policy | AI의 행동 규칙 | 운전자의 판단 |
| Cache | 과거 경험 저장소 | 메모장, 네비게이션 |
| Gradient Clipping | 학습량 제한 | 폭식 방지 |
| Dueling DQN | 상태+행동 분리 평가 | 위치 평가 + 선택 평가 |
| Double DQN | 판단과 평가 분리 | 선수 + 심판 분리 |
