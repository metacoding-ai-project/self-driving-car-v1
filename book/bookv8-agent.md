2. 역전파 설명을 조금 더 상세히 해야할것 같아
   예를 들어 a -> b -> c -> y(결과)
   이런 상황에서 y에 결과에 가장 영향을 많이 미치는 것은 c자나?
   하지만 a와 b도 영향을 미치는데 심층신경망중에 너무 앞에 있어서 영향이 적자나?
   그걸 합성곱을 통해서 영향을 얼마나 미치는지를 정확히 계산하자나?
   이런 개념을 초딩이 알기 쉽게 설명하면서도, 어느정도 숫자들이 들어가서 구체적인 방식을 볼 수 있어야 할것같아
   그래야 합성곱을 잘 이해할 것 같아
