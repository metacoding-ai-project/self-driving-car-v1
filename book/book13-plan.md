## 2. 더 쉽게 수정할 부분

### 2-1. 1화 뉴런 계산 섹션 — 비유가 너무 많음 (689~914줄)
현재 약 **225줄**에 비유가 4개나 등장합니다:
1. 화재 감지기 비유
2. 병원 진단 비유
3. 자동차 운전 비유
4. 전체 흐름 다이어그램

**수정:** 가장 직관적인 비유 **1개만** 남기기 (병원 진단이 가장 명확)
- 화재 감지기 → 삭제 (병원 비유와 역할이 겹침)
- 자동차 운전 → 삭제 (자율주행 자체가 이미 비유라서 비유의 비유가 됨)
- 전체 흐름 다이어그램 → 유지 (시각적으로 좋음)

### 2-2. 2화 경사하강법 + 역전파 + 연쇄법칙 — 너무 김 (1307~1657줄)
현재 약 **350줄**. 한 번에 소화하기 어렵습니다.

**수정:**
- 경사하강법: 산 비유 + 6단계 숫자 예시 → 유지하되 보폭 ASCII 아트 3개(1374~1430줄, 약 57줄)를 간략하게 축소
- 역전파: 유지 (0.21/0.09 계산 명확해서 좋음)
- 연쇄법칙: 전화 게임 비유만 유지, 숫자 계산 예시 축소

### 2-3. 활성화 함수 ReLU/Sigmoid — 위치가 어색
현재 1화에서 두 번 등장:
1. 뉴런 계산 3단계에서 ReLU 설명 (849줄)
2. 별도 섹션 "활성화 함수: ReLU와 Sigmoid" (921줄)

**수정:** 하나로 통합. 뉴런 계산 3단계에서 바로 ReLU를 설명하고, Sigmoid는 "프롤로그에서 본 그것! 여기서는 ReLU를 씁니다" 한 줄 연결.

## 3. 순서 변경

### 3-1. "AI에게 세상을 보여주는 방법" 섹션 → 1화에 통합
현재 이 섹션은 0화와 1화 사이에 독립적으로 존재합니다 (516~628줄).
하지만 상태 벡터, 전처리, 정규화, 보상 시스템은 모두 **AI를 만들기 시작할 때** 필요한 내용입니다.

**수정:** 1화 "드디어 AI를 만들다!" 시작 부분으로 이동. "AI를 만들기 전에, 먼저 AI에게 세상을 보여주는 방법을 정해야 합니다" 흐름으로 자연스럽게 연결.

### 3-2. Q값 설명 위치 조정
현재 Q값 개념이 뉴런 계산 섹션 끝 (916줄)에 갑자기 등장합니다.

**수정:** 1화 시작에서 DQN을 소개할 때 Q값을 먼저 간단히 설명 → 신경망 구조 → 뉴런 계산 순서로. "Q값이 뭔지 알았으니, 이제 이 Q값을 어떻게 계산하는지 보자!" 흐름.

### 3-3. Exploration vs Exploitation — 2화에서 앞으로 이동
현재 "해결책 3" 뒤에 나오지만 (1701줄), 사실 1화 문제 분석에서 epsilon 개념이 나올 때 함께 설명하는 게 자연스럽습니다.

**수정:** 1화의 학습 과정(ε=0.79 등장)에서 탐험/활용 개념을 간단히 도입. 2화에서는 "이 균형을 어떻게 조절하느냐가 핵심"으로 연결.

## 4. 문맥 연결이 약한 부분

### 4-1. 0화 → 1화 전환
현재: 0화 끝에 "AI를 만들자!" → 갑자기 "AI에게 세상을 보여주는 방법" 독립 섹션
**수정:** 0화 마지막에 "AI를 만들려면 먼저 결정해야 할 것이 있다: AI에게 뭘 보여줄 것인가?" → 1화로 자연스럽게 이어지게

### 4-2. 3화 → 4화 전환
현재: 팀장님 "학습이 오래 걸리는데 더 빨리 배우게 할 수 없나?" → 4화 LR Scheduling
**수정:** 이 연결 자체는 좋음. 유지.

### 4-3. 번외편 도입
현재: 5화가 끝나고 갑자기 "DQN 말고 다른 방법은?"
**수정:** 5화 마지막에 "73%... 90%까지 올리려면?" → 김선배 "DQN만이 정답은 아니야" → 번외편으로 자연스럽게 연결 (현재도 어느 정도 되어있지만 더 매끄럽게)
