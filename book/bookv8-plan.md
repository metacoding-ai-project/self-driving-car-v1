# bookv8-plan.md — 빠져있는 AI 개념을 자율주행 책에 넣는 계획

## 전략 요약

bookv7은 **강화학습(DQN) 중심**으로 진행되기 때문에, 빠져있는 개념들을 크게 두 가지로 나눕니다:

- **A. 기존 v0~v5 스토리 안에 자연스럽게 녹여넣을 수 있는 것** → 기존 화에 설명 추가
- **B. 새로운 시뮬레이터(simulator-v6)를 만들어야 넣을 수 있는 것** → 새 화 추가
- **C. 이 책 범위를 넘어서 빼는 것** → 에필로그 로드맵에서 이름만 언급

---

## A. 기존 화에 자연스럽게 녹여넣기

### A-1. 전처리 + 정규화 → 📍 1화(v1)에 추가

**현재 상황:** 1화에서 상태벡터(11개)를 만들 때 이미 전처리를 하고 있음 (벽 유무 → 0/1, 목적지 방향 → -1.0~+1.0)

**추가 내용:**
- "AI에게 세상을 보여주는 방법" 섹션에서 **"전처리(Data Preprocessing)"** 용어를 정식 소개
- 목적지 방향 -1~+1 변환 = **정규화(Normalization)**
- **왜 전처리가 필요한가?** 비유: "한국어, 영어, 중국어로 된 보고서를 하나의 언어로 통일하는 것"

**예시 추가:**
```
전처리 전: 거리 = 450m, 벽 = "있음", 방향 = "오른쪽"
전처리 후: 거리 = 0.6, 벽 = 1, 방향 = 1

→ AI는 숫자만 이해하니까, 모든 것을 숫자로 바꿔주는 것이 전처리!
```

**코드 변경:** 없음 (v1 코드에 주석만 추가)

### A-2. 분류 vs 회귀 + 선형 회귀 + 로지스틱 회귀 → 📍 프롤로그 또는 1화 앞에 "AI의 세 가지 문제 유형" 섹션 추가

**추가 위치:** 프롤로그에서 "DQN이 뭔지 검색하는 장면" 직후

**스토리:**
메타코딩이 AI를 검색하다가 "AI가 푸는 문제의 종류"를 먼저 정리하게 됨

**추가 내용:**
```
AI가 푸는 문제는 크게 3가지:

1. 회귀(Regression): "숫자를 예측해!"
   예: "내일 기온은 몇 도?" → 23.5도
   자율주행 예: "목적지까지 남은 거리는?" → 14.2칸

2. 분류(Classification): "어디에 속하는지 맞춰봐!"
   예: "이 메일은 스팸? 아님?" → 스팸!
   자율주행 예: "이 칸은 벽? 빈칸?" → 벽!

3. 강화학습(Reinforcement Learning): "시행착오로 최선을 찾아!"
   예: "직진? 좌회전? 우회전?" → 직진! (보상 기반)
   자율주행 예: 이 책이 다루는 것!
```

**선형 회귀 예제 (자율주행 맥락):**
```
"이동한 걸음 수와 소모 에너지의 관계를 직선으로 예측"

걸음 수 (x):  10  20  30  40  50
소모 에너지:  15  28  42  55  70

→ 직선: y = 1.4x + 1
→ 100걸음 걸으면? → 약 141 에너지!
→ 이게 선형 회귀! 직선(1차 함수)으로 미래를 예측!
```

**로지스틱 회귀 예제 (자율주행 맥락):**
```
"벽에 부딪힐 확률을 예측"

벽까지 거리:  1칸  2칸  3칸  5칸  10칸
충돌 확률:    95%  70%  40%  10%  2%

→ Sigmoid 함수로 확률(0~1)을 출력!
→ "아! 1화에서 배운 Sigmoid가 여기서 쓰이는 거구나!"
→ 이게 로지스틱 회귀! 확률로 분류하는 알고리즘!
```

### A-3. 모델 규제 (드롭아웃, 조기 종료) → 📍 3화(v3)에 개념만 소개

**현재 상황:** 과적합을 설명하고 "다양한 맵으로 학습"을 해결책으로 제시했지만, 규제 기법은 없음

**추가 위치:** 3화에서 훈련/테스트 분리 뒤에 "과적합을 막는 다른 방법도 있어!" 로 짧게 소개

**추가 내용 (개념만! 코드 변경 없음):**
```
과적합을 막는 다른 방법들도 있어!

1. 드롭아웃(Dropout):
   학습할 때 뉴런의 일부를 랜덤으로 끔
   비유: "조별 과제에서 한 명이 빠져도 나머지가 해낼 수 있도록 훈련"

2. 조기 종료(Early Stopping):
   테스트셋 성능이 떨어지기 시작하면 학습 중단
   비유: "더 공부하면 오히려 외우기만 해서 실력이 떨어진다"

3. L2 규제(Weight Decay):
   가중치가 너무 커지면 패널티!
   비유: "한 과목 100점보다 전 과목 80점이 더 좋은 대학"
```

**코드 변경:** 없음 (개념 소개만)

**추가 위치:** 4화 LR Scheduling 설명 뒤에

```
우리 AI가 쓰는 옵티마이저: Adam!

경사하강법(SGD)의 업그레이드 버전이야.
SGD는 모든 방향에 같은 보폭으로 걷지만,

비유:
  SGD = 직진만 하는 초보 스키어

```

### A-5. 에포크/이터레이션 → 📍 2화(v2)에 추가

**현재 상황:** "에피소드"는 사용하지만 에포크 개념 없음

**추가 위치:** 2화 경험 리플레이 설명 근처

**추가 내용:**
```
학습 단위 정리:

에피소드(Episode): 시작 → 목적지 도달(또는 실패)까지 한 판
  → 우리 자율주행에서 사용!

에포크(Epoch): 전체 데이터를 한 바퀴 돌린 것
  → 이미지 분류 같은 지도학습에서 사용!

이터레이션(Iteration): 미니배치 하나를 학습한 한 번
  → 우리 AI에서 경험 32개 뽑아서 학습하는 한 번!
```

### A-7. AI 학습 패러다임 전체 지도 → 📍 프롤로그 + 에필로그에 추가

이 책에서 배우는 개념들이 AI의 전체 그림에서 **어디에 해당하는지** 독자가 항상 알 수 있어야 합니다.
프롤로그에서 전체 지도를 먼저 보여주고, 각 화에서 "지금 배우는 건 여기야!"를 표시하고,
에필로그에서 다시 전체를 정리합니다.

```
1. 지도학습 (Supervised Learning): "정답을 알려주고 배우기"

   예: "이 사진은 고양이야" → AI가 고양이 특징을 배움

위 3가지 방식 모두에서 쓸 수 있는 "도구(신경망)"입니다!
```

## B. 새 화(simulator-v6)를 만들어 추가해야 하는 것

### B-1. 의사결정 트리 + 랜덤 포레스트 + 앙상블 → 📍 새로운 화 추가 제안

**왜 별도 화가 필요한가?**
- 트리 알고리즘은 신경망(DQN)과 완전히 다른 접근법
- 기존 v0~v5 스토리에 끼워넣기 어려움
- 하지만 AI 입문에서 가장 직관적이고 중요한 알고리즘

**제안: "번외편 — 다른 방법은 없을까?" (simulator-v6)**

**스토리 아이디어:**
```
메타코딩이 v5를 완성한 후, 김선배가 물어봄:
"DQN 말고 다른 방법으로도 자율주행을 만들 수 있는 거 알아요?"

메타코딩: "네? 다른 방법이요?"

김선배: "의사결정 트리라는 게 있어요.
신경망처럼 복잡한 계산 없이, '질문'만으로 판단하는 거예요."
```

**simulator-v6 내용:**

1. **의사결정 트리로 자율주행**
   - 학습 데이터: v5에서 성공한 경험들 (상태→행동)을 저장
   - 트리가 "앞에 벽이 있나? → Yes → 목적지가 오른쪽인가? → Yes → 우회전!" 으로 판단
   - **장점:** 왜 그렇게 판단했는지 설명 가능! (해석 가능성)
   - **단점:** 복잡한 상황에서 성능이 DQN보다 낮음

2. **랜덤 포레스트 (앙상블)**
   - 트리 100개를 만들어서 투표!
   - "80개 트리가 직진이래! → 직진!"
   - 앙상블 = "여러 모델의 투표"로 간단히 소개
   - **성능 비교:** 단일 트리 50% → 랜덤 포레스트 62% → DQN 73%

**simulator-v6 구현 방향:**
- v5에서 수집한 경험 데이터(상태, 행동)를 CSV로 저장
- scikit-learn으로 DecisionTree, RandomForest 학습
- 같은 시뮬레이터 환경에서 DQN vs 트리 vs 랜덤포레스트 성능 비교

### B-2. CNN → 📍 simulator-v6에 통합 또는 별도 설명

**제안: simulator-v6의 "시야 확장" 파트에서 CNN 개념만 소개 (코드 없이)**

**스토리:**
```
김선배: "지금 AI는 11개 숫자만 보잖아요.
만약 카메라처럼 '이미지'를 볼 수 있다면?"

메타코딩: "이미지? 30×30 맵 전체를 사진처럼?"

김선배: "맞아요! 그게 바로 CNN이에요.
이미지에서 '벽 패턴', '통로 패턴'을 자동으로 찾아내는 거예요."
```

**설명 내용:**
```
CNN의 핵심 아이디어:

1. 필터(Filter)로 이미지를 훑기
   3×3 크기의 필터가 맵 위를 슬라이딩하며
   "여기 벽이 있나?", "여기 통로가 있나?"를 감지

2. 풀링(Pooling)으로 핵심만 남기기
   30×30 → 15×15 → 7×7 으로 줄이면서
   중요한 특징만 남김

3. 완전연결층(FC)으로 판단
   추출한 특징들을 모아서 최종 결정!

우리 자율주행에 적용하면:
  현재: 주변 8칸만 봄 (11개 숫자)
  CNN: 맵 전체를 이미지로 봄 (30×30 = 900개 숫자)
  → 더 넓은 시야, 더 정확한 판단!
  → 하지만 학습이 훨씬 오래 걸림!
```

**실제 코드는 없이 개념만 소개. 실습은 다음 책으로 유도.**

### B-3. LSTM/RNN → 📍 simulator-v6에서 개념만 소개

**스토리:**
```
메타코딩: "그런데 자동차가 '어디서 왔는지'를 기억하면
더 똑똑해지지 않을까요? 같은 길을 또 가지 않게요."

김선배: "그게 바로 RNN, LSTM이에요!
'시간 순서'를 기억하는 신경망이에요."
```

**설명 내용:**
```
RNN/LSTM의 핵심:

일반 신경망: "지금 이 순간"만 봄
  → 입력: 현재 상태 11개 숫자
  → 이전에 어디 있었는지 모름!

RNN: "과거도 기억"함
  → 입력: 현재 상태 + 이전 기억
  → "아, 나 방금 왼쪽에서 왔으니까 왼쪽으로 가면 제자리야!"

LSTM: RNN의 업그레이드
  → 중요한 기억은 오래, 사소한 기억은 버림
  → "10걸음 전에 갈림길이 있었다"를 기억!

자율주행에 적용하면:
  현재: 매 순간 독립적으로 판단 (이전 기억 없음)
  LSTM: 최근 10걸음의 경로를 기억하며 판단
  → "이 길은 아까 와본 곳이야, 다른 길로 가자!"
```

**실제 코드는 없이 개념만 소개.**

```
비지도학습의 대표 알고리즘이죠."
```

**설명 내용 + 간단한 예제:**
```

100개 맵의 특성을 숫자로 표현:
  [벽 밀도, 통로 폭, 시작-목적지 거리]

K=3으로 클러스터링하면:
  그룹 A: 쉬운 맵 (벽 적음, 넓은 통로)
  그룹 B: 보통 맵 (중간 난이도)
  그룹 C: 어려운 맵 (벽 많음, 좁은 통로)

→ 그룹별로 커리큘럼 학습!
→ 쉬운 맵부터 → 보통 → 어려운 순서로 학습하면 효율적!
→ 이걸 "커리큘럼 러닝(Curriculum Learning)"이라고 해요!
```
