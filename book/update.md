### 문맥/내용 이슈

1. **Double DQN, Dueling DQN, PER**
   - 용어사전과 분류표에 등장하지만, 본문에서는 설명되지 않음
   - 6화(삭제됨)에서 다뤄질 예정이었던 것으로 추정
   - 제안: 용어사전에서 삭제하거나, 번외편에 간단한 개념 소개 추가

2. **"스스로" 표기**
   - 본문에 "스스로"가 여러 번 사용됨 (예: 180행, 479행 등)
   - "스스로" → "스스로" (표준어: "스스로"가 맞음, "스스로"는 비표준)
   - 전체 검색하여 일괄 수정 필요

3. **nanoimg SVG 파일 4개 수정 필요**
   - `nanoimg/nano_16.svg` — 정규화 이미지: 글자가 색상에 가려서 안 보임
   - `nanoimg/nano_1.svg` — 신경망 이미지: Q값 부분이 짤림
   - `nanoimg/nano_2.svg` — 경사하강법 이미지: 잘못 그려짐

4. **images 폴더의 실제 스크린샷**
   - `images/v0_main.png` ~ `images/v5_main.png` 등의 실제 파일 존재 여부 확인 필요
   - 시뮬레이터를 직접 실행해서 최신 스크린샷으로 교체하면 좋음
