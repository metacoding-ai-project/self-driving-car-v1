### 💡 가장 단순한 아이디어

메타코딩은 규칙을 떠올렸습니다.

"목적지가 오른쪽에 있으면 오른쪽으로. 아래쪽에 있으면 아래쪽으로. 벽이 막혔으면 다른 방향으로."

마치 나침반처럼 항상 목적지 방향으로 움직이되, 벽이 나오면 돌아가는 것이죠. 너무 간단한 것 같지만, 메타코딩은 일단 만들어봤습니다.

### 🔧 v0 코드 소개

```python
def decide_action(self, environment):
    goal_x, goal_y = environment.goal_pos

    # 목적지까지의 거리 계산
    dx = goal_x - self.x   # 양수 = 오른쪽, 음수 = 왼쪽
    dy = goal_y - self.y   # 양수 = 아래쪽, 음수 = 위쪽

    # 우선순위 방향 결정
    preferred = []
    if dx > 0:   preferred.append(RIGHT)
    elif dx < 0: preferred.append(LEFT)
    if dy > 0:   preferred.append(DOWN)
    elif dy < 0: preferred.append(UP)

    # 우선순위대로 벽이 없는 방향으로 이동
    for direction in preferred:
        next_x, next_y = 다음_위치(direction)
        if not environment.is_wall(next_x, next_y):
            return direction   # 이 방향으로!
```

### 💥 왜 실패했을까?

메타코딩은 화면을 멍하니 바라봤습니다. 자동차가 한 칸 앞에 목적지가 보이는데도 계속 제자리에서 돌고 있었습니다. 마치 미로에 갇힌 생쥐처럼.

**문제의 원인: 국소 최적화 함정 (Local Optima)**

```
상황을 생각해봐요:

목적지가 오른쪽에 있어요.
오른쪽은 벽!
→ 아래로 가자!

아래도 벽!
→ 위로 가자!

위도 벽!
→ 오른쪽으로 가자! (맨 처음과 같음)
오른쪽도 벽!
→ 아래로 가자!
...
(무한 반복!)
```

이것이 **국소 최적화 함정**입니다. 눈앞의 상황만 보고 결정을 내리다 보니, 가장 좋아 보이는 선택을 계속 하는데 결국 같은 자리를 맴돌게 되는 것이죠.

진짜 문제는 더 있었습니다. v0 규칙에는 **"경험"이 없습니다.** 1000번 실패해도 1001번째도 똑같이 실패합니다. 배우지 않으니까요.

```
❌ if 문 (규칙 기반):
   "막히면 이쪽, 막히면 저쪽"
   → 1000번 실패해도 배움 없음!

✅ AI (강화학습):
   "이 상황에서 오른쪽으로 갔더니 성공했어!"
   → 다음엔 더 잘함! 점점 발전!
```

## AI는 무엇을 보고 움직이는가?

본격적으로 AI를 만들기 전에, 메타코딩은 한 가지 중요한 질문을 스스로에게 던졌습니다.

### 🤔 AI에게 어떤 정보를 줄까?

"AI에게 뭘 알려줘야 하지? 전체 맵 정보를 다 줘야 할까?"

만약 전체 맵 정보를 준다면, AI는 그 맵만 외우게 됩니다. 맵이 바뀌면 아무것도 못 하죠.

"나침반처럼 방향만 알려주면 어떨까? '지금 목적지가 저쪽 방향이야. 그리고 바로 주변에 벽이 있어.' 이 정도만 알려줘도 충분하지 않을까?"

이 아이디어가 핵심이었습니다.

### 📊 AI가 받는 정보 (상태 벡터, 총 11개)

```
AI가 보는 것:

     [왼위벽] [위벽] [오른위벽]
        (0)    (1)     (0)
[왼쪽벽]  🚗  [오른쪽벽]
  (0)            (0)
[왼아래벽] [아래벽] [오른아래벽]
   (1)      (0)      (0)

+ 현재 방향: 오른쪽(→)
+ 목적지 dx: +0.6 (오른쪽으로 60% 거리)
+ 목적지 dy: +0.4 (아래쪽으로 40% 거리)

총 11개 숫자로 현재 상황을 표현!
```

이 11개 숫자가 AI의 "눈"입니다. 전체 맵 정보가 아니라, 지금 내 주변과 목적지 방향만 아는 것이죠.

**왜 11개일까요?**
- 주변 8칸 벽 유무 (8개)
- 지금 내가 바라보는 방향 (1개)
- 목적지까지 X 방향 거리 (1개)
- 목적지까지 Y 방향 거리 (1개)
- 합계: **11개**

### 🎯 보상 시스템 (AI에게 칭찬과 꾸중)

AI가 정보만 받는다고 배우는 건 아닙니다. **칭찬(보상)** 과 **꾸중(패널티)** 이 있어야 무엇이 좋고 나쁜지 알 수 있죠.

```python
if 목적지 도달:
    reward = +100   # "완벽해! 계속 이렇게 해!"
elif 목적지에 가까워짐:
    reward = +0.5   # "잘 하고 있어!"
elif 충돌:
    reward = -10    # "안 돼! 조심해야지!"
elif 시간 초과:
    reward = -50    # "너무 오래 걸렸어!"
```

이걸 **보상 함수(Reward Function)** 라고 합니다. AI의 교육 시스템이라고 보면 됩니다. 사람으로 치면 선생님이 숙제에 점수를 매겨주는 것처럼요.

### 🧠 AI 핵심 개념 1: 신경망(Neural Network)이란?

> **"AI의 뇌를 만드는 방법"**

신경망은 인간의 뇌를 모방해서 만든 수학적 모델입니다. 인간의 뇌가 수많은 뉴런이 연결되어 있듯, 신경망도 수많은 숫자 계산이 연결되어 있습니다.

우리 AI의 신경망은 이렇게 생겼습니다:

```
입력층 (11개 숫자)           은닉층 (64개 뉴런)      출력층 (3개 Q값)
┌─────────────────────┐                            ┌──────────────────┐
│ ① 왼위벽?  = 0      │──┐                     ┌─▶│ 직진   Q = 8.5   │
│ ② 위 벽?  = 1      │  │   ┌─────────────┐  │  │ 우회전 Q = 3.2   │
│ ③ 오른위벽?= 0      │──┤   │             │  │  │ 좌회전 Q = 2.1   │
│ ④ 왼쪽벽? = 0      │  ├──▶│  64개 뉴런  │──┘  └──────────────────┘
│ ⑤ 오른쪽벽?= 0      │──┤   │  (계산중)   │
│ ⑥ 왼아래벽?= 1      │  │   │             │
│ ⑦ 아래벽? = 0      │──┤   └─────────────┘
│ ⑧ 오른아래?= 0      │  │
│ ⑨ 현재방향 = 오른쪽 │──┤         ↑
│ ⑩ 목적지dx = +0.6  │──┤    각 뉴런이
│ ⑪ 목적지dy = +0.4  │──┘    가중치 × 입력을 더해서
└─────────────────────┘    최종 Q값을 계산
```

AI는 이 신경망에 11개 숫자를 넣으면, 자동으로 "직진/우회전/좌회전" 중 어느 것이 가장 좋은지 Q값으로 알려줍니다. **Q값이 가장 높은 행동을 선택**하면 됩니다!

#### 은닉층 뉴런은 어떻게 계산할까?

은닉층의 뉴런 하나가 어떻게 계산하는지 살펴봅시다.

```
[뉴런 하나의 계산 과정]

입력값들 × 가중치(w) 더하기:

값 = (0 × 0.3) + (1 × 0.8) + (0 × 0.1) + (0 × 0.5)
    + (0 × 0.2) + (1 × 0.7) + (0 × 0.4) + (0 × 0.1)
    + (오른쪽 × 0.6) + (0.6 × 0.9) + (0.4 × 0.3) + 편향(0.1)

  = 0 + 0.8 + 0 + 0 + 0 + 0.7 + 0 + 0 + 0.6 + 0.54 + 0.12 + 0.1
  = 2.86

그런 다음 활성화 함수(ReLU) 적용:

ReLU(2.86) = 2.86  ← 양수니까 그대로!
ReLU(-1.3) = 0     ← 음수면 0으로!
```

64개 뉴런이 각각 이런 계산을 하고, 그 결과들이 다시 합쳐져서 최종 Q값이 만들어집니다.

### 🧠 AI 핵심 개념 2: 활성화 함수 (ReLU vs Sigmoid)

뉴런 계산에서 마지막에 **활성화 함수**를 적용한다고 했죠. 왜 필요할까요?

활성화 함수가 없으면 신경망이 아무리 깊어도 결국 "큰 곱셈+덧셈" 하나와 같아집니다. 활성화 함수가 있어야 **비선형** 문제(복잡한 미로 같은!)를 풀 수 있어요.

```
[두 가지 대표적인 활성화 함수]

① ReLU (우리 AI가 사용!)
   규칙: 음수면 0, 양수면 그대로

   출력
   │      /
   │     /
   │    /
   0────── 입력
        (음수는 0)

   특징: 계산이 빠름, 현재 가장 많이 쓰임

② Sigmoid
   규칙: 어떤 값이든 0~1 사이로 압축

   출력
   1 ─── ────────────
   │     /
   0.5──/──────────── 입력
   │  /
   0 /

   특징: 확률 표현에 유리 (ex: "성공 확률 73%")

우리 v1~v5는 ReLU를 사용합니다.
```

### 🧠 AI 핵심 개념 3: Q값과 DQN

**Q값**은 "이 상황에서 이 행동을 하면 얼마나 좋을까?"를 나타내는 점수입니다.

```
[현재 상황: 목적지가 오른쪽 아래, 앞길은 열려있음]

Q(현재 상황, 직진)   = 8.5  ← 가장 높음! → 이 행동 선택
Q(현재 상황, 우회전) = 3.2
Q(현재 상황, 좌회전) = 2.1

AI는 Q값이 가장 높은 "직진"을 선택!
```

처음에는 이 Q값이 엉망입니다. AI가 아무것도 모르니까요. 그러다 실패를 경험하면서 "이 상황에서 이 행동은 나빠"를 배우고, 성공을 경험하면서 "이 상황에서 이 행동은 좋아"를 배웁니다.

**이 과정을 반복하면 Q값이 점점 정확해집니다. 이게 DQN의 핵심입니다!**

### 🧠 AI 핵심 개념 4: 경사하강법 (Gradient Descent)

> **"AI가 실수로부터 배우는 방법"**

AI가 새로운 맵에서 학습을 할 때, 내부에서는 어떤 일이 벌어질까요? 바로 **경사하강법**이 작동합니다.

#### 🏔️ 비유: 눈 감고 산 내려오기

여러 봉우리가 있는 복잡한 산을 상상해보세요.

```
손실(Loss)
높을수록 = AI가 틀린 것!

          ⛰️              ⛰️
   /│\   /│\         /│\
  / │ \ / │ \       / │ \
 /  │  V  │  \     /  │  \
/   │  ↑  │   \   /   │   \
    │ 로컬 │   V──V    │
    │ 미니마│  ← 잘못된       │
    │ (함정)│    최저점 발견!  │
    │      │               │
    └──────┴───────────────┴──▶ 가중치
                    ↑
              진짜 최저점!
              (여기를 찾아야 함)
```

눈을 감고 이 산을 내려와야 합니다. 전체 지도가 없으니 발로 경사를 느끼면서 한 걸음씩 내려가야 하죠.

**경사하강법 전략:**
1. 발로 경사를 느낀다 → **미분(기울기) 계산**
2. 가장 가파르게 내려가는 방향으로 한 걸음 → **가중치 업데이트**
3. 다시 경사를 느끼기 → **반복**

#### ⚠️ 함정: 로컬 미니마 (Local Minima)

```
손실(Loss)
   │
   │   ⛰️   ⛰️   ⛰️
   │  /│\  /│\  /│\
   │ / │ \/ │ \/ │ \
   │/  │  V │  V │  \
   │   │  ↑ │  ↑ │    \
   │   │ 가짜 가짜 │     \
   │   │최저점      │      \_____
   │                          ↑
   └──────────────────── 진짜 최저점!
```

눈을 감고 발로만 경사를 느끼다 보면, "가짜 최저점(로컬 미니마)"에 빠질 수 있습니다. 그 자리에서는 모든 방향이 올라가는 것처럼 느껴지거든요. 하지만 실제로는 더 낮은 곳이 멀리 있습니다.

#### 👣 보폭(Learning Rate)이 중요한 이유

```
[너무 큰 보폭 - 최저점을 지나쳐버림!]

손실│    ●          ← 시작점
    │      ↘
    │        ×      ← 최저점
    │          ↗
    │            ●  ← 지나쳐서 반대편으로!
    └──────────────▶

큰 보폭으로 성큼성큼 내려갔더니
최저점을 지나쳐서 반대편으로 가버림!


[너무 작은 보폭 - 너무 오래 걸림!]

손실│    ●  ← 시작점
    │    ↓
    │    ↓ (아주 조금씩...)
    │    ↓
    │    × ← 최저점 (도달은 하지만 너무 느림!)
    └──────────────▶


[딱 맞는 보폭 - 빠르고 정확하게!]

손실│    ●
    │      ↘
    │        ↘
    │          ×  ← 최저점 도달! ✅
    └──────────────▶
```

#### 🎯 최적의 전략: 처음엔 크게, 나중엔 작게!

```
[Learning Rate Scheduling - 가장 효율적인 방법!]

1단계: 큰 보폭으로 전체를 훑는다
  손실│●
      │ ↘↘↘↘  ← 빠르게 대략적인 최저점 찾기!
      │      ↘
      │       ●
      └──────────────▶

2단계: 작은 보폭으로 정밀하게 찾는다
  손실│●
      │   ↓ ↓ ↓  ← 천천히 진짜 최저점 찾기!
      │         ×
      └──────────────▶

→ 빠르면서도 정확! 이게 v4에서 해결하는 핵심!
  (자세한 내용은 4화에서!)
```

#### AI에서 경사하강법이 실제로 어떻게 동작하나?

```
[v2에서 한 번의 학습 과정]

1단계: AI가 Q값 예측
   현재 상황 → 신경망 → Q(직진) = 7.0

2단계: 실제 결과 확인
   실제로 직진하니 목적지에 가까워짐!
   올바른 Q값(정답): 10.0

3단계: 오차(Loss) 계산
   오차 = (예측값 - 정답)²
        = (7.0 - 10.0)² = 9.0
   → "많이 틀렸네!"

4단계: 기울기(Gradient) 계산 - 미분!
   기울기 = 오차가 어느 방향으로 줄어드는가?
   = 2 × (7.0 - 10.0) = -6.0
   → "음수니까 Q값을 올려야 함!"

5단계: 가중치 수정
   새 Q값 = 7.0 + (학습률 × 6.0) = 7.6
   → "10.0에 조금 가까워졌네!"

6단계: 이걸 3000번 반복!
   7.0 → 7.6 → 8.1 → 8.9 → 9.5 → 10.0
   → 점점 정확해짐!
```

**기울기(Gradient)** 가 바로 미분의 개념입니다. "오차를 줄이려면 가중치를 어느 방향으로, 얼마나 바꿔야 하나?"를 알려주는 나침반 같은 것이죠.

### 🔧 해결책 3: 천천히 탐험 줄이기 (Epsilon 감소)

**Epsilon (ε)** 은 "새로운 것을 시도할 확률"입니다.

```
ε = 1.0 (100%): "모험가 모드! 뭐든 새롭게 시도!"
ε = 0.5 (50%): "절반은 시도, 절반은 아는 길로"
ε = 0.0 (0%):  "베테랑 모드! 배운 것만 활용!"
```

```python
# v1 (빨리 탐험을 줄임)
self.epsilon_decay = 0.995  # 금방 0에 가까워짐

# v2 (천천히 탐험을 줄임)
self.epsilon_decay = 0.998  # 오래 탐험 유지
```

**왜 중요할까요?**

```
v1의 문제:
Episode 1   : ε = 1.0 (100% 탐험) "뭐든 해봐!"
Episode 50  : ε = 0.6 (60% 탐험)  "좀 알아가는 중"
Episode 100 : ε = 0.4 (40% 탐험)  "이제 아는 길로"
Episode 200 : ε = 0.1 (10% 탐험)  "거의 아는 길만"

→ 너무 빨리 탐험을 포기해서 다양한 길을 못 배움!

v2의 개선:
Episode 100 : ε = 0.9 (90% 탐험)  "아직 많이 탐험"
Episode 500 : ε = 0.6 (60% 탐험)  "여전히 탐험 중"
Episode 1000: ε = 0.4 (40% 탐험)  "배워가는 중"
Episode 2000: ε = 0.1 (10% 탐험)  "이제 활용 시작"

→ 충분히 탐험한 후에 활용 단계로 전환! ✅
```

### 🧠 AI 핵심 개념 5: Exploration vs Exploitation

> **"탐험 vs 활용 - AI의 영원한 딜레마"**

```
새로운 식당을 가봐야 할까, 단골 식당에 가야 할까?

탐험 (Exploration):
"오늘은 저 골목 새 식당에 가볼까?"
→ 더 맛있는 곳을 발견할 수도!
→ 하지만 실망할 수도 있음

활용 (Exploitation):
"역시 우리 동네 단골집이 최고야!"
→ 안전하지만 새로운 발견 없음

딜레마:
탐험만 하면 → 배운 것을 써먹지 못함
활용만 하면 → 더 좋은 방법을 놓침

해결책:
처음엔 탐험 많이 → 나중엔 활용 위주
(=Epsilon이 처음엔 높고, 나중엔 낮아짐)
```

### 🧠 AI 핵심 개념 6: Learning Rate Scheduling

> **"처음엔 빠르게 훑고, 나중엔 세밀하게!"**

2화에서 봤던 경사하강법의 최적 전략을 기억하시나요?

```
[처음: 큰 Learning Rate = 큰 보폭]

많이 틀린 단계:
손실│ ●
    │  ↘↘↘↘  ← 빠르게 내려감! (LR = 0.001)
    │         ↘
    │          ●
    └──────────────▶
전체 패턴을 빠르게 파악!

[나중: 작은 Learning Rate = 작은 보폭]

거의 다 온 단계:
손실│ ●
    │   ↓ ↓ ↓  ← 조금씩 정밀하게! (LR = 0.0001)
    │         ×
    └──────────────▶
세밀하게 최저점 찾기!
```

```
책 읽기에 비유하면:

1단계: 빠르게 훑어보기 (큰 Learning Rate)
   "우선 목차랑 소제목만 쭉 읽어보자!"
   → 전체 구조 파악! 빠름!

2단계: 꼼꼼하게 읽기 (중간 Learning Rate)
   "이제 본문을 차근차근 읽어보자"
   → 내용 이해!

3단계: 중요 부분 정독 (작은 Learning Rate)
   "이 문단은 정말 중요하니까 세 번 읽자!"
   → 완벽한 이해!

→ 처음부터 천천히 읽는 것보다 훨씬 효율적!
```

### 🔧 v4 코드 소개

```python
class DQNAgent:
    def __init__(self):
        self.initial_lr = 0.001  # 처음: 빠르게
        self.min_lr = 0.0001     # 마지막: 세밀하게

    def update_learning_rate(self, episode):
        decay_rate = 0.998
        self.current_lr = self.initial_lr * (decay_rate ** episode)
        self.current_lr = max(self.current_lr, self.min_lr)

        # 옵티마이저에 적용
        for param_group in self.optimizer.param_groups:
            param_group['lr'] = self.current_lr
```

### 🧠 AI 핵심 개념 7: 학습 vs 추론

```
[청소 로봇의 두 단계]

학습 (Training):
→ AI가 배우는 과정
→ 공장에서 한 번 (몇 시간~며칠)
→ 완료 후 모델 파일(.pth) 저장

추론 (Inference):
→ 배운 걸 실제로 사용하는 과정
→ 매번 청소할 때마다!
→ 빠를수록 배터리 절약, 반응 빠름

사람으로 비유:
학습: 운전 면허 학원 다니기 (한 번)
추론: 매일 출근길 운전 (매일)
```

### 💡 메타코딩의 아이디어: 캐싱!

"그러고 보니... 같은 집에서 매일 청소하면 비슷한 경로로 다니는데, 매번 신경망 계산(45ms)을 하는 게 낭비 아닐까?

이미 성공한 경로를 저장해두면 더 빠르지 않을까?"

```
네비게이션에 비유하면:

서울-부산 매번 새로 계산 (느림):
"경로를 다시 계산합니다... 45분 걸립니다." ❌

자주 가는 길은 저장 (빠름):
"저장된 경로입니다! 바로 안내합니다." ✅
```

### 🔧 캐싱 시스템 코드 소개

```python
class ActionCache:
    """성공한 경험을 저장하는 캐시"""
    def __init__(self):
        self.cache = {}  # 상태 → 행동 매핑

    def get(self, state):
        state_key = tuple(round(x, 2) for x in state)
        return self.cache.get(state_key, {}).get('action', None)

    def store(self, state, action, success):
        if success:  # 성공한 행동만 저장!
            state_key = tuple(round(x, 2) for x in state)
            self.cache[state_key] = {'action': action}
```

### 💡 두 가지 전략: 정적 vs 동적 환경

선배가 핵심을 짚어줬습니다.

"캐시를 쓸 때는 환경에 따라 전략을 달리해야 해요."

**전략 1: 정적 환경 (장애물이 고정된 창고, 공장)**
```
캐시에 있으면 → 캐시 사용! (12ms, 3.75배 빠름!)
캐시에 없으면 → 신경망 계산 (45ms)
```

**전략 2: 동적 환경 (사람이 다니는 실제 가정)**
```
항상 신경망(Policy)이 먼저! (45ms, 하지만 안전!)
캐시는 참고만 → 다르면 신경망 우선!
```

현재 v5는 교육용이라 항상 Policy를 먼저 계산해서 안전성을 보장합니다.

### 🤔 왜 73%에서 막혔을까?

### 🔍 부족한 부분 1: 중요한 경험을 자주 복습 안 함

현재 v5에서는 모든 경험을 동등하게 취급합니다.

```
경험 창고:
┌────────────────────────────────────────┐
│ 경험 1: 이동 중 (평범)                 │
│ 경험 2: 이동 중 (평범)                 │
│ 경험 3: 목적지 도달!! (귀하고 중요!)  │
│ 경험 4: 이동 중 (평범)                 │
│ 경험 5: 이동 중 (평범)                 │
└────────────────────────────────────────┘

문제: 학습할 때 위 5개에서 랜덤하게 뽑음
→ "목적지 도달" 같은 귀한 경험이 잘 안 뽑힘!
→ 정작 중요한 순간을 덜 배움!
```

**해결책: Prioritized Experience Replay (PER)**

```
중요도 기반으로 뽑기!

┌────────────────────────────────────────┐
│ 경험 3: 목적지 도달!! (우선순위 높음) │ ← 자주 뽑힘!
│ 경험 1: 벽에 충돌 (우선순위 중간)    │ ← 가끔 뽑힘
│ 경험 2: 이동 중 (우선순위 낮음)      │ ← 드물게 뽑힘
└────────────────────────────────────────┘

기대 효과: +5~8% 성공률 향상!
```

### 🔍 부족한 부분 2: 같은 신경망이 판단+평가를 다 함

현재 DQN의 구조:

```
현재 구조:
Policy Network (신경망 하나)
역할 1: "어떤 행동이 좋을까?" (판단)
역할 2: "그 행동이 얼마나 좋은가?" (평가)
         ↕
      자기가 좋다고 한 행동을 자기가 평가?
      → 편향될 수밖에 없음! (자기 자신에게 후한 점수)
```

**해결책: Double DQN**

```
개선된 구조:
┌──────────────────┐       ┌──────────────────┐
│ Policy Network   │       │ Target Network   │
│ "어떤 행동이     │ ──▶   │ "그 행동의 가치  │
│  좋을까?" (판단) │       │  는?" (평가)     │
└──────────────────┘       └──────────────────┘

판단하는 역할과 평가하는 역할을 분리!
→ 더 객관적인 학습!

기대 효과: +3~5% 성공률 향상!
```

### 🔍 부족한 부분 3: 신경망 구조가 단순함

```
현재 신경망:
입력(11개) → 은닉층(64개) → Q값(3개)

문제: 64개 뉴런으로 복잡한 판단을 다 하기엔 부족!
```

**해결책: Dueling DQN**

```
Dueling DQN 구조:

입력(11개) → 은닉층 ─┬─▶ [상태 가치 V] ─┐
                    │                  ├─▶ Q값(3개)
                    └─▶ [행동 이점 A]  ─┘

왜 분리할까요?

V(상태가치): "지금 이 위치 자체가 얼마나 좋은가?"
   예: 목적지 바로 옆 = 매우 좋은 위치

A(행동이점): "직진이 우회전보다 얼마나 더 나은가?"
   예: 직진하면 빨리 도달, 우회전하면 벽 충돌

→ 위치 판단 + 행동 판단을 따로 배움!
→ 더 정확한 Q값!

기대 효과: +4~7% 성공률 향상!
```

### 🎯 1화: 과적합과 신경망

```
과적합: 아는 것만 잘하고 새로운 건 못 함
신경망: 입력(11개) → 은닉층(ReLU) → Q값(3개)
ReLU: 음수면 0, 양수면 그대로 (빠르고 효과적!)
Q값: "이 상황에서 이 행동은 얼마나 좋은가?"
```

### 🎯 2화: 경사하강법과 다양성

```
경사하강법:
  - 오차(Loss)를 줄이는 방향으로 가중치 수정
  - 기울기(Gradient) = 미분 = "어느 방향으로?"
  - 보폭(Learning Rate) = "얼마나 크게?"
  - 로컬 미니마 함정: 가짜 최저점에 빠질 수 있음

다양성의 힘:
  - 랜덤 시작 방향
  - 여러 맵 학습
  - 천천히 탐험 줄이기
```

### 🎯 3화: 훈련셋 vs 테스트셋

```
훈련셋: 공부하는 문제집
테스트셋: 처음 보는 시험 문제

같은 문제로 평가하면 실력이 아닌 암기!
반드시 새로운 데이터로 평가해야 진짜 실력 측정!
```

효과: 25% 빠른 학습!

### 💡 메타코딩이 진짜 배운 것

기술적인 것들 말고, 메타코딩이 이번 프로젝트에서 진짜 배운 것은 따로 있었습니다.

**첫째: 실패가 교과서다**

v1의 실패가 없었다면 과적합을 몰랐을 것입니다. v2의 불확실성이 없었다면 훈련셋/테스트셋 개념을 그냥 지나쳤을 것입니다. 모든 실패가 다음 버전을 만드는 재료가 됐습니다.

**둘째: 한 번에 완벽할 필요 없다**

```
v0 → v1 → v2 → v3 → v4 → v5 → ...

처음부터 v5를 만들려고 했다면?
→ 너무 복잡해서 포기했을 것

한 번에 하나씩 개선하면?
→ 결국 v5까지 도달!
```

**셋째: "왜?"를 이해하면 "어떻게?"가 보인다**

73%가 왜 나왔는지 이해했더니, 어떻게 90%로 올릴 수 있는지 자연스럽게 보였습니다.

### 🎓 이 책에서 배운 AI 개념 총정리

```
✅ 강화학습 (Reinforcement Learning)
   보상과 패널티로 스스로 배우는 AI

✅ DQN (Deep Q-Network)
   AI의 뇌 - 상황을 보고 Q값을 계산

✅ Q값 (Q-value)
   "이 상황에서 이 행동은 얼마나 좋은가?"

✅ 신경망 (Neural Network)
   입력 → 은닉층 → 출력 (뇌를 흉내 낸 수학)

✅ 활성화 함수 (ReLU, Sigmoid)
   ReLU: 음수는 0, 양수는 그대로
   Sigmoid: 0~1 사이로 압축 (확률 표현)

✅ 경사하강법 (Gradient Descent)
   오차를 줄이는 방향으로 가중치를 조금씩 수정

✅ 기울기/그래디언트 (Gradient)
   "오차를 줄이려면 어느 방향으로?"를 알려주는 미분값

✅ 과적합 (Overfitting)
   아는 것만 잘하고 새로운 건 못 하는 현상

✅ 일반화 (Generalization)
   새로운 상황에서도 잘 작동하는 능력

✅ Epsilon-Greedy (탐험 vs 활용)
   처음엔 탐험, 나중엔 배운 것 활용

✅ Learning Rate (학습률)
   한 번에 얼마나 크게 배울지 조절

✅ Learning Rate Scheduling
   처음엔 크게, 나중엔 작게

✅ 훈련셋 / 테스트셋
   공부용 문제와 평가용 문제는 반드시 분리

✅ 캐싱 (Caching)
   성공 경험 저장으로 추론 속도 향상

✅ Double DQN
   판단과 평가를 분리해서 객관적으로

✅ Dueling DQN
   위치 가치와 행동 이점을 분리해서 더 정밀하게

✅ Prioritized Experience Replay
   중요한 경험을 더 자주 학습
```
