4. 아래 부분에서 왜 0.09, 0.21이 나왔는지가 이해안가 수정해줘 (더 많은 영향을 미친다는건 알겠어, 근데 0.09, 와 0.21이 그냥 예시인지 해깔려)

뉴런A의 가중치 = 0.7 → 출력에 70% 영향
  → 오차의 70%는 A 책임! → A의 가중치를 많이 올리자!
  → 새 가중치: 0.7 + 0.21 = 0.91

뉴런B의 가중치 = 0.3 → 출력에 30% 영향
  → 오차의 30%는 B 책임! → B의 가중치는 조금만 올리자!
  → 새 가중치: 0.3 + 0.09 = 0.39
